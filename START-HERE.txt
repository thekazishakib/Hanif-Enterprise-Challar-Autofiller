Bus Challan - Bengali and English

1. Extract the ZIP. Python 3.10+ is required. Run setup.cmd the first time.
2. Open challan-input.xlsx. On the Counters sheet, enter your real counter names and commissions.
3. The Routes sheet already has Dhaka-Chattogram at 300 BDT. Add other routes if needed.
4. Fill in Trip Details. In Main and Secondary, choose a Counter for every seat that has a passenger. Save.
5. Open run.cmd, choose a language, and click Save NEW challan. Both language forms are created.
6. To print the same challan again, click Reprint saved. No new number is used.

Numbers: 01/2026 -> 02/2026 -> 03/2026 ...
Main and Secondary share one number. The year comes from the Main trip date.

Signatures: use Draw signature to make a PNG, or use your own PNG/JPEG.
Keep the image next to the Excel file and enter its name in Signature File on the Counters sheet.

Fixed signatures: put booking-master.png, manager.png and checker.png in the signatures folder.
They are added to every challan automatically. See signatures/README.txt.

Register: once challan-register.sqlite3 exists, keep it with the app.
Bengali prints use the bundled Noto Serif Bengali font (keep the fonts folder).
Full rules are in README.md. The sample PDFs only show the blank form layout.
