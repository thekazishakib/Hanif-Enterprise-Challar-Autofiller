Put your fixed signature images here. Use exactly these file names:

  booking-master.png   (Booking master)
  manager.png          (Manager)
  checker.png          (Checker)

.jpg or .jpeg also works. PNG with a transparent background looks best.
Each image must be under 2 MB and at most 4000 pixels.
They are added to every new challan automatically. If a file is missing, that
signature line stays blank for hand signing.

You can also point to files elsewhere in settings.json, for example:
  "manager_signature": "C:/Users/me/Documents/manager.png"
Keys: booking_master_signature, manager_signature, checker_signature
